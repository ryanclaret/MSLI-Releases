# MSLI-Releases
MSLI Integrated Management System

A desktop management system built for Montenegro Shipping Lines Inc. (MSLI) to handle day-to-day inventory / item tracking operations in one place.


Overview

MSLI Integrated Management System is a Windows desktop application that centralizes the company's operational record-keeping — replacing manual, spreadsheet-based tracking with a structured database-backed tool. It was designed and built as an end-to-end solution, from database schema through the user-facing application.


Tech Stack
